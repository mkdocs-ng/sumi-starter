# 安装

需要 Python 3.10 或更高版本。

```sh {tab="pip"}
pip install my-project
```

```sh {tab="uv"}
uv add my-project
```

```sh {tab="pipx"}
pipx install my-project
```

确认安装成功：

```console
$ my-project --version
my-project 1.0.0
```

> [!NOTE]
> 把这些命令换成你项目自己的。标签相同的选项卡会在全站同步：读者选过一次 **uv**，其他页面也会显示 uv。
