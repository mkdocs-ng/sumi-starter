# Install

My Project needs Python 3.10 or newer.

```sh {tab="pip"}
pip install my-project
```

```sh {tab="uv"}
uv add my-project
```

```sh {tab="pipx"}
pipx install my-project
```

Check that it works:

```console
$ my-project --version
my-project 1.0.0
```

> [!NOTE]
> Replace these commands with your project's own. Tabs with the same labels stay in sync across the site, so a reader who picks **uv** once sees uv everywhere.
